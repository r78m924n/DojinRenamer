# DojinRenamer
FANZA &amp; DLsite 自動リネーム＆整理ツール

FANZA（同人）および DLsite の作品ファイル（ZIPや動画など）を、CID（コンテンツID）をもとに自動でスクレイピングし、統一されたルールで美しくリネーム・フォルダ整理を行うPythonスクリプトです。

## ✨ 主な機能

* **複数サイト・複数フォーマット対応**
  * FANZA (`d_` から始まるCID)
  * DLsite (`RJ` および `VJ` から始まるCID)
* **高度な情報取得とリネーム**
  * 作品ページから「サークル名」「タイトル」「作品形式」「販売日」「更新日」「バージョン情報」を自動取得。
  * `[サークル名][CID][作品形式][販売日] タイトル Ver1.0.zip` の形式で自動リネーム。
  * タイトル内のバージョン表記揺れや、更新日からの自動バージョン推測（`Update_YYYYMMDD`）に対応。
* **サムネイル画像の自動取得**
  * リネーム後のファイル名と同名の `.jpg` でパッケージ画像を自動保存。
  * DLsiteの「販売終了作品」や「ユーザー限定作品」などページが開けない場合でも、CIDから画像URLを直接計算して推測取得する強力なフォールバック機能を搭載。
* **スマートな実行とクリーンアップ**
  * 対象リスト（`url.txt`）をスキャンし、必要なサイトの初期化（年齢確認の突破など）だけを無駄なく実行。
  * 処理が成功したCIDは `url.txt` から自動で削除され、次回以降の重複処理を防止。

## 📁 ディレクトリ構成

ツールを実行する前に、スクリプトと同じ階層に `targets` フォルダを作成してください。

```text
.
├── renamer.py         # 本スクリプト
└── targets/           # 処理対象を入れるフォルダ（自動作成されます）
    ├── url.txt        # (任意) CIDを改行区切りで羅列したテキストファイル
    ├── d_123456.zip   # リネーム対象のファイル（FANZA）
    └── VJ123456.mp4   # リネーム対象のファイル（DLsite動画）
